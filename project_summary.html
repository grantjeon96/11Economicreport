프로젝트 개발 내역 및 구조 요약 보고서

💡 프로젝트 개요

본 프로젝트는 글로벌 거시 경제 지표, 국내외 주요 주식, ETF, 환율, 원자재 및 암호화폐 등 총 19개 핵심 지표의 데이터를 왜곡 없이 실시간으로 모니터링하고 시각화하는 통합 시스템입니다. 매일 아침 수집된 요약 데이터를 바탕으로 인공지능 브리핑 대본을 작성하고, HTML 메일 발송 및 로컬 스피커를 통한 TTS 알림을 수행합니다.

🛠️ 핵심 구현 기술 스택

Backend API (Python)

  • FastAPI + Uvicorn 기반의 비동기 웹 API 구현
  • yfinance API 활용 데이터 정밀 수집 및 결측치(ffill/bfill) 처리
  • Matplotlib를 이용한 2중 축(Dual Y-Axis) 결합 분석 차트 생성
  • Windows TTS(SpeechSynthesizer)와 winsound 연동 오디오 알람 구현

Frontend Dashboard (React)

  • Vite 빌드 도구 기반의 초경량 고성능 아키텍처
  • 프리미엄 Glassmorphism 다크 테마 UI 디자인
  • Chart.js를 적용한 개별 지표 상세 차트 및 5종 통합 비교 차트 시각화
  • 웹 화면에서 수집, 메일 전송, 알람 듣기를 제어하는 통합 컨트롤러 탑재

🚀 금일 추가 반영 및 수정된 내역

  • 기능 추가 CNN 공포와 탐욕 지수(FNG) 연동 완료: 야후 파이낸스 데이터 외에 CNN Dataviz API를 직접 크롤링하여 공포 탐욕 지수 데이터 연동 및 전용 해석 멘트 추가.
  • UI 개선 소수점 한자리 표기 강제 통일: 대시보드 상세페이지, 카드 리스트, 툴팁 내 모든 지표 수치의 포맷을 소수점 첫째자리(예: 1,350.0)로 고정하여 가독성 강화.
  • 성능 개선 음성 브리핑 낭독 속도 2배속 설정: 사용자 피드백을 수용하여 PowerShell SpeechSynthesizer 속도(Rate) 옵션을 4에서 2배속 체감인 6으로 상향 조정.
  • 오류 조치 Gemini API 호출 모델명 변경: 기존 미지원 모델명인 gemini-3-flash를 구글 API 스튜디오에서 정상 서비스 중인 최신 gemini-2.0-flash로 변경하여 연동 검증.
  • 오류 조치 Localhost 접속 및 서비스 기동 오류 해소: PowerShell 실행 정책 차단 우회를 위해 npm.cmd 기동 방식을 도입하여 프론트엔드와 백엔드 서비스를 모두 정상 백그라운드 가동.

📂 시스템 디렉토리 구조

11.경제지표모으기/
├── backend/
│   ├── data/                 # 수집된 JSON 데이터 및 생성된 차트 이미지 저장
│   ├── alarm.py              # winsound 알람 연주 및 PowerShell 한국어 TTS 낭독
│   ├── collector.py          # yfinance & CNN FNG 크롤러
│   ├── notifier.py           # Matplotlib 차트 생성 및 이메일 전송 (SMTP)
│   ├── main.py               # FastAPI 기반 서버 컨트롤러
│   └── .env                  # 로컬 환경 변수 설정 파일 (Git 제외)
├── frontend/
│   ├── src/                  # React 컴포넌트 및 Glassmorphism CSS 스타일링
│   ├── index.html
│   └── vite.config.js
├── run_daily.bat             # 스케줄러 등록용 원클릭 일괄 구동 스크립트
├── register_scheduler.bat    # 윈도우 작업 스케줄러 자동 등록용 배치 스크립트
└── README.md                 # 사용자 통합 매뉴얼 및 가이드

🔒 보안 안내 (비밀번호 및 API Key 보호)

보안 유지를 위해 개인 Gmail SMTP 앱 비밀번호와 Gemini API Key가 포함된 .env 파일들은 .gitignore를 통해 원격 GitHub 저장소(Repository) 업로드 시 안전하게 제외되었습니다.

💻 로컬 개발 환경 기동 방법

백엔드 API 서버 작동

.\.venv2\Scripts\python.exe backend/main.py

프론트엔드 대시보드 기동 (frontend 폴더로 이동 후)

npm.cmd run dev

기동 완료 후 브라우저에서 http://localhost:5173으로 접속합니다.
